# utils/

Drop the organizer-provided `validate_submission.py` in this folder (it is distributed
with the challenge materials, not authored by us - do not hand-write a substitute and
treat it as the official check).

For fast local iteration before running the official script, use
`src/business_entity_resolution/validation/local_checks.py`, which implements the same
rules as a developer convenience - see CLAUDE.md §3 and §9 for when each must be run.
